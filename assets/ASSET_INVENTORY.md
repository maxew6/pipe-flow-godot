# Asset inventory

All images are ORIGINAL work generated by the scripts in `tools/art/` (Python: Pillow, numpy, scipy).
No third-party artwork. Fonts are SIL Open Font License (licence files included in assets/fonts).

**Honest quality note:** these are procedurally generated, layered illustrations (shaded volumes, textures,
baked lighting). They are a clear step up from flat shapes, but they are not hand-painted art. Every asset
is designed to be swapped for commissioned/AI-generated art without code changes (specs below).

| File(s) | What | Source | Swap spec |
|---|---|---|---|
| assets/menu/sky, cloud_1..4, mountains, midground, river, scenery, fg_tl, fg_bl, fg_br .png | Menu scenery layers (1200x2400 art space) | tools/art/build_menu.py | Easiest swap: one finished 1200x2400 PNG at `assets/menu/override/bg_full.png` - MenuStage shows it instead of the layers (no motion) |
| assets/menu/fall_streaks.png, river_glints.png | Tiling overlays for waterfall / river motion | build_menu.py | Keep tileable (128x512 vertical, 512x256 horizontal), white with alpha |
| scripts/ui/menu_art_layout.gd | Layer rectangles (generated) | build_menu.py | Regenerated with the layers |

## Still procedural (to be replaced in later stages)
Pipe tiles and joints, stone tiles, board frame, water tank, tap, water rendering, level-complete effects,
level-category plank and rosette emblem. These are drawn in code today.

## Regenerate
```
pip install pillow numpy scipy
python3 tools/art/build_menu.py
python3 tools/art/ui_assets.py
```
Then reopen the project in Godot so it re-imports the PNGs.
